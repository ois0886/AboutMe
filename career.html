LS증권 Android 차트 라이브러리

  • 문제: 여러 지표 변수를 연속 편집할 때 일부 변경값이 누락됐습니다. 키패드의 입력 결과를 닫기 애니메이션 완료 콜백에서 전달하던 흐름을 보완해야 했습니다.
  • 해결: 입력 결과 전달을 애니메이션 완료 시점에서 분리하고 결과 전달 여부를 관리해 취소와 종료 과정의 중복 전달을 방지했습니다.
  • 결과: 연속 편집한 지표 변수의 변경값이 누락되던 오류를 수정했습니다.
  • 문서화: API 사용 방법과 관심종목 3분할 차트 예제를 포함한 개발 및 샘플 매뉴얼을 작성하고 갱신했습니다.
  • 이동평균선 설정 행을 다시 바인딩하기 전에 체크박스와 Spinner 리스너를 해제하고 모델 상태를 적용한 뒤 다시 연결했습니다. 색상 선택 전에 입력값을 모델에 반영해 체크 상태와 편집값이 유지되도록 수정했습니다.
  • Signal 기간 및 이평 설정 항목의 목록 인덱스와 엔진 파라미터 대응을 보완했습니다.
  • 수평선과 추세선의 가격 입력이 반영되도록 연결하고, 심볼과 도형의 속성 변경이 해당 대상에 적용되도록 보완했습니다.
  • 테마 리소스를 해석하지 못할 때 기본 색상을 사용하도록 예외 처리했습니다.
  • 숫자 문자열 검사에 막히던 소수점과 음수 변수를 Double 값으로 파싱해 저장하도록 수정했습니다.
